# Mafia21

Това е минимален фронтенд scaffold за проекта Mafia21 — добавих
прост index.html/index.js и стилове, за да можеш бързо да стартираш
демонстрация локално.

Как да стартираш фронтенда локално

1) Изтегли репото локално (или работи в GitHub):
   git clone https://github.com/Ivo0o0o/Mafia21.git

2) Отвори директорията frontend и стартирай прост HTTP сървър (за да
   избегнеш CORS проблеми при зареждане на локални файлове):

   cd Mafia21/frontend
   python3 -m http.server 8000

3) Отвори в браузър: http://localhost:8000
